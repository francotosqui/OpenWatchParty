# OpenWatchParty Documentation

OpenWatchParty is a Jellyfin plugin and session server for shared media playback. Version 0.7 includes room chat, shared playback controls, episode queues with an up-next countdown, expiring invite links, and host recovery and transfer. See the [feature guide](product/features.md) for the full list.

The illustrated [first watch-party tutorial](product/first-watch-party.md) walks through installation, server authentication, and joining as a second user. Operators can start with [installation](operations/installation.md), [deployment](operations/deployment.md), and [security](operations/security.md). Developers can start with [development setup](development/setup.md), [testing](development/testing.md), and [contributing](development/contributing.md).
